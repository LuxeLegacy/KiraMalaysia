## Calculator Type Patterns

### Pattern 1: Comparison Calculators
**Examples:** BonusVsSalaryComparison, CompanyAVsCompanyBSalaryComparison, ResidentVsNonresidentTaxComparison

**Required Elements:**
- Side-by-side input forms (Scenario A vs Scenario B)
- Comparison table showing differences
- Visual chart comparing tax burdens
- "Winner" recommendation with reasoning
- Crossover point analysis

**Inputs:**
- Scenario A: Annual Income, reliefs, other parameters
- Scenario B: Annual Income, reliefs, other parameters

**Unique FAQs:**
- Which scenario is better for my situation?
- What's the break-even point?
- Should I consider non-monetary benefits?
- How do I use this for negotiations?
- What if I'm between tax brackets?

---

### Pattern 2: Breakdown/Checker Calculators
**Examples:** PayslipBreakdownCalculator, AllowanceTaxabilityChecker, TaxReliefCalculator

**Required Elements:**
- Multiple input fields for each component
- Line-by-line breakdown table
- Taxable vs non-taxable categorization
- Actionable optimization tips
- What-if scenarios

**Inputs:**
- Basic salary
- Each allowance type separately
- Bonus/commission
- Benefits in kind

**Unique FAQs:**
- Which allowances are taxable?
- How to structure compensation for tax efficiency?
- What documentation do I need?
- Can I claim this as a deduction?
- What happens if LHDN audits me?

---

### Pattern 3: Projection/Tracker Calculators
**Examples:** YtdTaxTracker, MonthlyIncomeProjection, MtdCalculator

**Required Elements:**
- Month selector or date range
- Month-by-month table or chart
- Cumulative totals
- Projection to year-end
- Over/under payment indicators

**Inputs:**
- Current month
- Income to date
- PCB/tax paid to date
- Expected remaining income
- Expected bonuses

**Unique FAQs:**
- Am I on track for year-end?
- Will I get a refund or owe tax?
- How much should I set aside?
- When should I adjust my PCB (TP1)?
- What if my income varies monthly?

## Content Requirements for Each Page

### 1. Unique Calculator Logic (Required)
- Minimum 3 input fields (not just income + reliefs)
- Calculation specific to the calculator's purpose
- At least one unique insight or comparison
- Proper error handling and validation

### 2. Specific FAQs (Minimum 5 questions)
**Bad (Generic):**
- "How do I use this calculator?" ❌
- "Is this calculator accurate?" ❌
- "Do I need to create an account?" ❌

**Good (Specific):**
- "How is overtime taxed differently from regular salary?" ✅
- "Can I deduct vehicle expenses as a Grab driver?" ✅
- "What's the tax difference between bonus and salary increase?" ✅

### 3. Unique Educational Content
**Required sections:**
- What Is It: Explain the specific scenario (not generic)
- How It Works: Explain the specific calculation method
- Who Needs It: Target audience for THIS calculator
- Key Benefits: Specific to this calculator's purpose

### 4. Helpful Input Labels
**Bad:** "Annual Income (RM)" ❌
**Good:** "Annual Salary (excluding bonuses and allowances)" ✅

### 5. Contextual Insights
**Bad (Generic):** "Your effective tax rate is X%" ❌
**Good (Specific):** "Your overtime is taxed at 24% marginal rate. Consider negotiating higher base salary instead." ✅
